Hope UI open-source visual reference
Source: https://github.com/iqonicdesignofficial/hope-ui-design-system/
The Sign2Digital Laravel Admin Panel uses the user's supplied Hope UI HTML
dashboard as a reference for layout and interface patterns. The Laravel UI is
re-authored with Sign2Digital's palette and components. No demo datasets,
template frameworks, or vendor JavaScript are embedded.
